- patch-social-duplicate (SOCIAL_TODO C2, part 3: the same text again and again; needs patch-rate-limit-db and patch-new-account-limits first): a new Social post or a new reply is REFUSED when the SAME person already sent the same text within the last 24 hours (`socialDuplicate.windowHours` in `site.ts`). "Same" ignores capital letters, spaces, line breaks, punctuation, emoji and zero-width characters (Unicode NFKC, then only letters, numbers and combining marks are kept, so "Buy NOW!!" = "buy now"; Sinhala, Hindi, Arabic and Chinese text compare correctly; a different number or web address is a different text). A text with fewer than 12 letters/numbers after that cleaning (`socialDuplicate.minChars`) is never a repeat, so "thanks" or "+1" can be said twice. Posts are compared with the person's own posts of the last 24 hours (hidden posts count; deleted posts have no text), replies with their own replies under ANY post (the usual spam pattern). The check runs in the same database transaction as the save, after the rate limit, and BEFORE the picture is written to disk, so a refused post leaves no file. Rules in `src/lib/social-duplicate.ts` (pure: `normalizeForCompare`, `isRepeat`); `createSocialPost` and `createSocialReply` answer `duplicate: true`; the post box and the reply box show a new message. 2 new texts in six languages (`social.form.duplicate`, `social.reply.duplicate`). NO DATABASE CHANGE. New test `npm run test:social-duplicate` (no database). Not done on purpose: the same text from DIFFERENT accounts (a spam network; needs a hash column or a text search, decide later), almost-the-same texts (one word changed), checking edits and quote-repost texts, a note that tells the person how long to wait. With this patch SOCIAL_TODO C2 is complete.
